### Feature Request
#### Description
Add functionality to automatically export .mscz files to .pdf upon upload.

#### Proposed Behavior
1. Export the uploaded .mscz files as .pdf automatically.
2. Store the PDFs in the same file explorer, perhaps displaying the .mscz file as a folder.
3. The exported file should maintain the same name as the .mscz file but have a .pdf extension.

#### Constraints
- The .pdf export will be handled via Musescore.
- The implementation details for Musescore integration are still to be determined.
- No customization options will be provided for the PDF export.
